Airbnb analysis

Hosts and guests use the same platform but talk about neighborhoods differently. This project mined Airbnb listings and reviews across New York to map the difference.

Role
Data visualization, in a team of five
Product
Interactive website
Timeline
Spring 2017
Links
Project site ↗

01Context

A neighborhood’s identity is partly marketing. Hosts describe the places they list; guests describe the places they stayed. Both write on the same platform, but do they describe the same neighborhood?

02Approach

Text from guest reviews and host listings across the five boroughs was mined, grouped by theme and mapped, so the same word could be compared between hosts and guests, borough by borough.

03Outcome

An interactive site that maps the words each group uses most, with word associations by theme. Made with Rachael Dottle, Eric Wong, Clara Dykstra and Andreea Seusan, for Juan Saldarriaga’s data visualization course.
