01Google Earth · Interaction design, front end

Drag to select

Draw a box on the map, select every place inside it, and style them all at once. Before this, places on the map could only be picked one at a time.

Role
Interaction design and front-end engineering, sole engineer
Product
Google Earth, web
Status
Live
Links
Bulk styling docs ↗

01The problem

Places could be selected one at a time on the map, or several at once from the project panel. It was slow and unintuitive, and a real limit for power users and complex work.

Google Earth also needed a temporary drawing state for features on the way. Drag to select would be the first to use it, so it had to set the pattern.

02The work

Selection already worked three ways: checkboxes, dragging in the panel, and clicking items. The new gesture had to fit with all of them, across:

  • Web and mobile. One idea, two very different kinds of input.
  • Streamlined and productivity layouts. Simple by default, fast for power users.
  • Screen-centered drawing tools. Other tools also claim the middle of the map, so the gestures can’t collide.

Each of these was worked out by prototyping, testing and iterating closely with a UX designer and a PM. All of the implementation was one engineer.

03The result

Drag to select is live in Google Earth on the web, and it’s the first feature built on Earth’s new drawing state.
