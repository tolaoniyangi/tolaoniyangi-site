08Sidewalk Labs · Summer 2019 · Computational design

Estimating pedestrian activity

Generative design tools need good data about streets. I built a pipeline that estimates street-level foot traffic and feeds it straight in.

Role
Computational design summer associate
Team
Generative Design, Sidewalk Labs
When
Summer 2019
Tools
Python, GIS

01The bottleneck

Getting geospatial data into generative design was slow and manual, which kept the tools stuck on narrow test cases. I researched which use cases mattered most and which standard datasets, like pedestrian activity and transit access, they needed.

02The pipeline

I automated pulling the data in. Then I split census population and workforce counts down to individual buildings to estimate activity at street level. I built it on a test site and confirmed it held up in other cities and over larger areas.
